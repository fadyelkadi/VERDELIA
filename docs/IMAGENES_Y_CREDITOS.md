## Fuentes consultadas

Se revisó PNGimg como prioridad. Sus fichas de [Aloe Vera #104840](https://pngimg.com/image/104840) y [Cactus #3811](https://pngimg.com/image/3811) muestran PNG transparente y licencia CC BY-NC 4.0. No se incorporaron esos archivos: para mantener una sola dirección fotográfica local y evitar atribuir exactitud de especie a imágenes dispares, se generó un conjunto ilustrativo propio. Ningún archivo de PNGimg se incluye en el repo.

El archivo `docs/design-references/home-hero-reference.png` es una referencia interna de composición; no se carga como elemento de la página. El copy final de la web se implementa en HTML real y no depende del texto dentro de esa imagen.
